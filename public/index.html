Embed in one line

Drop the loader anywhere; it builds a responsive, lazy-loaded iframe.

Script loader

<script src="https://your-host/embed.js"
        data-video="vid_example"
        async></script>

Plain iframe

<iframe src="https://your-host/e/vid_example"
        allow="autoplay; fullscreen; picture-in-picture"
        allowfullscreen></iframe>
